Cómo renovar el token
  1. En Zabbix: Users › API tokens › Create API token, para el usuario sicma_api y con fecha de vencimiento.
  2. Reemplaza ZABBIX_TOKEN en Software/Backend/.env.
  3. Reinicia la API y la sincronización de Zabbix (cierra sus ventanas y ejecuta iniciar_sicma.ps1).
  4. Usa «Probar» aquí y, si funciona, elimina el token antiguo en Zabbix.

Cómo renovar la contraseña
  1. En tu cuenta de Google: Seguridad › Contraseñas de aplicación, crea una nueva.
  2. Reemplaza la variable de usuario de Windows EMAIL_HOST_PASSWORD (Configuración › «Editar las variables de entorno de esta cuenta»). Ponerla en el .env no sirve: la de Windows tiene prioridad.
  3. Cierra las ventanas de SICMA y ejecuta iniciar_sicma.ps1 desde una ventana nueva de PowerShell.
  4. Usa «Probar» aquí y, si funciona, revoca la contraseña antigua en Google.
